## Legend
- **FKs:** `col→target [ondelete]`. `?` means the FK column is nullable. No `[..]` means NO ACTION.
- **org_id:** present / NULL-ability / whether a leading index exists / whether the class is `OrgScoped` (read guard). **absent** means the table has no org_id, so tenancy can only be derived through a parent FK.
- **Uniques:** `+org` means the key includes `org_id`. `WHERE` marks a partial index.
- **Checks:** every table is `none`; listed per row so the gap shows.
- **Money/qty:** `N(p,s,flt)` = `Numeric(p,s, asdecimal=False)` (float in Python); `N(p,s)` = Decimal; **FLOAT** = binary float column; `int` = an Integer counter.
- **Notable defaults:** `srv:` = server_default. Python defaults are shown only for status/kind/mode/active-type columns. Money columns default to `0`/`0.0` almost everywhere.
- **ORM cascade:** only relationships with `delete`/`delete-orphan`. No relationship uses `passive_deletes`.
